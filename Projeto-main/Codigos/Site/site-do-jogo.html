Tutorial do Jogo

Aprenda os comandos básicos para jogar! Use as teclas W, A, S, D ou as setas do teclado para movimentar o personagem. Pressione a tecla E para interagir com os terminais de código e a tecla Espaço para acessar o robôzinho assistente. Analise cada desafio de lógica com atenção para desbloquear a próxima fase!

Sobre Nós

O projeto consiste no desenvolvimento de um jogo educativo criado para integrar os conhecimentos das disciplinas de Desenvolvimento de Sistemas e Desenvolvimento Web no Instituto Federal. O jogo contará com quatro fases, cada uma apresentando novos desafios que exigirão lógica, criatividade e resolução de problemas. Além da criação do jogo, estamos desenvolvendo este site para apresentar o projeto, explicar seu funcionamento e disponibilizar informações sobre o desenvolvimento. O objetivo é colocar em prática os conteúdos aprendidos durante o curso, demonstrando a aplicação dos conhecimentos em um projeto completo e interativo.
