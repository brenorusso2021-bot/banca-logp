# Avaliação.exe

Projeto desenvolvido por cinco alunos do IFSP (Instituto Federal de São Paulo) para uma banca de jogos promovida pelo curso de Desenvolvimento de Sistemas.

## Sobre o projeto

Avaliação.exe é um jogo educativo baseado em desafios relacionados às áreas estudadas durante o curso.

O projeto é composto pelo jogo e por um site complementar.

## Estrutura do repositório

- `Documentação/` — documentos de planejamento e acompanhamento do projeto.
  - `GDD/` — Game Design Document.
  - `Documento-Mestre/` — documento de acompanhamento geral do projeto.
  - `Relatorios/` — relatórios produzidos durante o desenvolvimento.

- `Projeto-main/` — materiais utilizados no desenvolvimento.
  - `Codigos/GameMaker/` — código e projeto do jogo.
  - `Codigos/Site/` — código do site.
  - `Visual/` — materiais visuais do projeto.

- `Associados-entrega/` — arquivos destinados às entregas do projeto.
